## ⚠️ الخطوة 1 (إلزامية): تثبيت بايثون

### الطريقة التلقائية (موصى بها — بدون إنترنت):
1. اضغط **نقرتين مزدوجتين** على **`install_python.bat`**
2. سيتم تثبيت **أحدث إصدار من Python** المرفق داخل الحزمة مع إضافته إلى `PATH` وتثبيت `pip` و`py` launcher.

### الطريقة البديلة: Python Install Manager
```powershell
install_python.bat -UseManager
```
أو اضغط نقرتين على **`python-manager-26.4.msix`** ← **Install**، ثم في PowerShell:
```powershell
py install default
py list
```

## ▶️ الخطوة 2: بناء وتشغيل البرنامج

اضغط نقرتين على **`run_claude_code.bat`** أو اكتب في PowerShell داخل المجلد:

```powershell
py claude_code_suite.py
```

سيقوم البرنامج تلقائياً بـ:
1. تثبيت المكتبات المطلوبة (`anthropic`, `pyinstaller`, `pillow`, ...)
2. إنشاء الشعار والأيقونة
3. تحميل `claude.exe` الرسمي مسبقاً
4. بناء `ClaudeCode.exe`
5. تجميع `dist\ClaudeCode_Setup.exe` وتشغيل معالج التثبيت (اختيار مجلد التثبيت + الاختصارات + PATH)

أوامر إضافية:

```powershell
py claude_code_suite.py --app     # تشغيل الواجهة مباشرة بدون بناء
py claude_code_suite.py --setup   # تشغيل معالج التثبيت فقط
```

## 🔑 الخطوة 3: مفاتيح API (OpenRouter / DeepSeek)

لأسباب أمنية **لا توجد أي مفاتيح داخل الكود المرفوع على GitHub**. أضف مفاتيحك بإحدى الطريقتين:

- **من داخل البرنامج:** اكتب الأمر `/keys` (تُحفظ محلياً على جهازك فقط في `~/.claude_code_gui_config.json`)
- **أو عبر متغيرات البيئة:**
  ```powershell
  setx OPENROUTER_API_KEY "sk-or-v1-..."
  setx DEEPSEEK_API_KEY  "sk-..."
  ```

## 📱 Hamza Link — تكامل الحاسوب والهاتف

تحكّم بحاسوبك من هاتفك **وبالعكس**، عبر نفس شبكة Wi-Fi، بدون أي مكتبات إضافية وبدون متجر تطبيقات.

### التشغيل
1. على الحاسوب: اضغط نقرتين على **`run_hamza_link.bat`** — أو اكتب `/phone` داخل Claude Code.
2. تفتح **لوحة الحاسوب** تلقائياً وفيها **رمز QR** ورمز اقتران من 6 أرقام.
3. على الهاتف: امسح رمز QR بالكاميرا (أو افتح الرابط الظاهر وأدخل الرمز) ← **اتصال**.
4. (اختياري) من قائمة المتصفح اختر **«إضافة إلى الشاشة الرئيسية»** ليعمل كتطبيق.

> عند أول تشغيل قد يسألك جدار حماية Windows — اختر **السماح على الشبكات الخاصة**.

### 📱 من الهاتف ← التحكم بالحاسوب
| الميزة | الوصف |
|---|---|
| 🖱️ لوحة لمس | تحريك الماوس، نقرة = يسار، نقرة بإصبعين = يمين، إصبعان للتمرير، وضع السحب |
| 🖥️ عرض الشاشة | بث مباشر لشاشة الحاسوب + النقر على الصورة للنقر في نفس المكان |
| ⌨️ لوحة المفاتيح | كتابة نصوص (تدعم **العربية**) + اختصارات: Ctrl+C/V/Z، Alt+Tab، Win+D… |
| 🎛️ الوسائط | الصوت، كتم، تشغيل/إيقاف، السابق/التالي، **قفل الحاسوب** |
| 📋 الحافظة | جلب حافظة الحاسوب / النسخ إليها + فتح روابط على الحاسوب |
| ✳️ Claude | **جلسة مشتركة**: نفس المحادثة تظهر على الهاتف والحاسوب مباشرةً |
| 💻 الطرفية | تنفيذ أوامر PowerShell (مغلقة افتراضياً — تُفعّل من الحاسوب) |
| 📁 الملفات | تصفح ملفات الحاسوب وتنزيلها + إرسال صور وملفات إلى `التنزيلات\Hamza Link` |

### 🖥️ من الحاسوب ← التحكم بالهاتف
| الميزة | الوصف |
|---|---|
| 🔔 رنين | صوت تنبيه واهتزاز مستمر للعثور على الهاتف |
| 📳 اهتزاز / ✨ إشعار | تنبيه فوري على شاشة الهاتف |
| 🗣️ نطق | الهاتف ينطق النص بصوته (عربي / إنجليزي) |
| 💬 نص / 🔗 رابط / 📎 ملف | إرسال فوري للهاتف (يُسلَّم لاحقاً إن كان غير متصل) |
| 📷 طلب صورة | الهاتف يفتح الكاميرا ويرسل الصورة للحاسوب |
| 📋 طلب الحافظة / ℹ️ معلومات الجهاز | البطارية، الشبكة، الشاشة، النظام… |

### 🛡️ الأمان
- رمز الاقتران **لمرة واحدة** ويتغيّر بعد كل اقتران، ولكل هاتف مفتاح خاص يمكن إلغاؤه من لوحة الحاسوب.
- لوحة الحاسوب تعمل من الحاسوب نفسه فقط (`127.0.0.1`) مع حماية من CSRF.
- كل صلاحية (الماوس، الشاشة، الملفات، الحافظة، Claude، الطرفية) لها مفتاح تشغيل/إيقاف في لوحة الحاسوب.
- يعمل داخل شبكتك المحلية فقط — لا يمر أي شيء عبر خوادم خارجية (عدا طلبات Claude إلى OpenRouter / DeepSeek).

## ⌨️ الأوامر داخل البرنامج

| الأمر | الوظيفة |
|------|---------|
| `/model [name]` | تبديل النموذج (`fable` / `opus` / `sonnet` / `deepseek-flash` / `deepseek-reasoner`) |
| `/usage` أو `/cost` | عرض استهلاك التوكن والتكلفة |
| `/clear` | مسح المحادثة وتصفير السياق |
| `/cd <path>` | تغيير مجلد العمل |
| `/official` | فتح `claude.exe` الرسمي في PowerShell |
| `/keys` | عرض أو تعديل مفاتيح OpenRouter و DeepSeek |
| `/phone` | تشغيل **Hamza Link** وربط الهاتف |
| `/help` | عرض المساعدة |
