# 🎮 NEON ROYALE

باتل رويال كامل يعمل في المتصفح — **بناء (Building) + عاصفة + 64 لاعبًا + loot + سكنات + متجر يومي + موسم ومستويات** — مع مختبر **هندسة عكسية تعليمي قانوني**.

> **أصول هذا المشروع أصلية 100%**: كل شخصية وسلاح وسكينة وأثر حركة مرسومة بالكود (`canvas 2D`) داخل المستودع. لا يحتوي المشروع أي ملف أو صورة أو صوت من Fortnite أو Rocket League أو أي لعبة تجارية، ولم يُستخرج من أي منتج محمي. مشروع تعليمي مستقل وليس بديلًا عن أي لعبة.

---

## تشغيل

```bash
cd neon-royale
node server.js        # أو: npm start
# افتح http://localhost:3000
```

لا توجد اعتماديات npm — Node 18+ فقط. البيانات تُحفظ في `data/db.json` (تُنشأ تلقائيًا).

## المحتوى

| الملف | الوصف |
|---|---|
| `server.js` | سيرفر HTTP + REST API (بروفايل، متجر، شراء، تجهيز، نتائج) |
| `shared/catalog.js` | كتالوج السكنات + ندرات + أسعار + مولّد متجر يومي (مشترك بين السيرفر والمتصفح) |
| `public/js/game.js` | حلقة اللعبة: حركة، إطلاق hitscan، ذكاء اصطناعي لـ63 بوت، بناء، عاصفة، loot |
| `public/js/render.js` | رسم الشخصيات/الفؤوس/الحركات على canvas |
| `public/js/main.js` | المتجر، الخزانة، الإحصائيات، ربط HUD بشاشة النتائج |
| `tools/headless-test.mjs` | اختبار تشغيل كامل بدون متصفح (لوبيكي/قتال) |
| `tools/render-preview.py` | توليد `preview.png` لمعاينة الرسم خارج المتصفح |
| `LEARN_REVERSE_ENGINEERING.md` | خارطة طريق تعلّم RE بشكل قانوني |
| `lab/crackme.c` | تحدي crackme مكتوب خصيصًا للتدريب (لا علاقة له بأي لعبة) |

## الميزات داخل اللعبة

**اللعب**
- 64 متنافسًا (أنت + 63 بوت) على خريطة 3000×3000 وحدة.
- أسلحة: مسدس، رشاش، بندقية، شوزن، قناص — مع تشتت، ارتداد، تعبئة، وضرر رأس.
- **بناء**: جدار / منحدر / أرضية بتكلفة موارد (خشب، حجر، معدن).
- **عاصفة** تتقلّص على مراحل مع تحذير وأضرار.
- Loot موزّع على الخريطة + إسقاطات من المُقصَين.
- عدّاد أحياء، إقصاءات، أرقام ضرر، خريطة مصغّرة، شاشة نتائج.

**التحكم**
| المفتاح | الوظيفة |
|---|---|
| `W A S D` | حركة |
| `Shift` | جري |
| زر الماوس الأيسر | إطلاق / بناء |
| زر الماوس الأيمن | إلغاء وضع البناء |
| `Tab` | تبديل وضع البناء |
| `1` `2` | جدار |
| `3` | منحدر |
| `4` | أرضية |
| `E` | تبديل السلاح |
| `R` | تعبئة |
| `F` | التقاط |

**الميتا (Meta)**
- متجر يومي: 6 عناصر تتغيّر كل يوم بتوقيت UTC + خصم على العنصر الأول + عدّاد تنازلي.
- عملات من المباريات + مكافأة يومية بسلسلة أيام (streak).
- خبرة ومستويات حتى 50، وإحصائيات دائمة (مباريات/انتصارات/إقصاءات/ضرر).
- خزانة (Locker) لتجهيز الزي/حقيبة الظهر/الفأس/أثر الحركة.

## اختبار

```bash
node tools/headless-test.mjs            # محاكاة مباراة كاملة (اللاعب يقف في المركز)
node tools/headless-test.mjs --combat   # سيناريو قتال: اللاعب يطلق على البوتات
```

كلاهما يطبع ملخصًا (إقصاءات، ضرر، عدد الأحياء، مراحل العاصفة، عدد الجدران) وينجح إذا وصلت المباراة إلى نهاية.

```bash
cd lab && ./build.sh    # بناء تحدي crackme للتدريب
```

## REST API

| المسار | الوصف |
|---|---|
| `POST /api/profile` | إنشاء بروفايل ← يرجع token |
| `GET /api/me` | بياناتي (Bearer token) |
| `GET /api/shop` | متجر اليوم + حالة الملكية |
| `POST /api/daily` | مكافأة اليوم (مرة واحدة يوميًا) |
| `POST /api/buy` | شراء عنصر معروض اليوم |
| `POST /api/equip` | تجهيز عنصر مملوك |
| `POST /api/match-result` | رفع نتيجة المباراة → عملات + خبرة |
